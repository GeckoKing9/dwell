# Dwell

Screen time for websites, counted the way a person would count it, kept entirely in your browser.

Dwell is a personal Chrome extension. It attributes each second to the site in the focused window's active tab, only while you are present, keeps 90 days of per-day, per-hour, per-site totals locally, shows today in a popup and the week in a dashboard, and turns Instagram Reels, YouTube Shorts and Facebook Reels off per site with one tap.

Status: planning and design complete, implementation in progress. See `docs/plans/` for the plan and `design/` for the design system and prototype.
